# Novation — дизайн-прототип сайта

Дизайн-прототип сайта digital-агентства **Novation**: «помогаем бизнесу привлекать клиентов, продавать и развиваться в интернете». Это эталон визуального языка будущего сайта.

## Страницы
- `index.html` — главная: первый экран с оффером и CTA, Яндекс Бизнес (ключевой продукт), Авито, сайты и интернет-магазины, реклама (Яндекс Директ и VK Ads), маркетплейсы / SEO / автоматизация, преимущества, процесс, контакты и финальный CTA.
- `services.html` — услуги: указатель направлений, липкая навигация по разделам, крупные блоки приоритетных услуг (сайты, Яндекс Бизнес, Авито, интернет-магазины, реклама), сетка дополнительных направлений и типовые связки каналов.

## Технологии
Чистые HTML + CSS + JS, без сборки и зависимостей. Шрифты Unbounded и Onest (Google Fonts). Все иллюстрации собраны из CSS/SVG, внешних картинок нет.

## Запуск локально
Откройте `index.html` в браузере или запустите любой статический сервер:
```bash
npx serve .
```
Деплой на Netlify: публикуется корень репозитория (см. `netlify.toml`).
