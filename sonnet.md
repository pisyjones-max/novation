# Инструкция для Sonnet 5.5 — продолжение сайта Novation

Ты продолжаешь работу над сайтом digital-агентства Novation. Две готовые страницы (`index.html`, `services.html`) — **эталон**. Все новые страницы должны выглядеть как их часть.

## Перед началом
1. Прочитай `AGENTS.md` и `assets/styles.css` (раздел `:root` и компоненты).
2. Открой `index.html` и `services.html`, чтобы увидеть ритм секций.

## Правила дизайна
- Светлый фон `--paper`, чернильный текст `--ink`, один акцент `--signal`, лаймовый маркер `--lime`. Новые цвета не добавлять.
- Заголовки — Unbounded, плотный трекинг (−0.035…−0.06em). Текст — Onest.
- Ритм страницы: светлые секции, чередуемые с одним тёмным блоком `.stage` и финальным `.cta-final`.
- Каждая секция начинается с `.sec-head` (`.eyebrow` + `h2` + короткий абзац).
- Используй готовые компоненты, а не новые: `.btn`, `.chip`, `.ticks`, `.tile`, `.svc-card`, `.more`, `.form`.
- Анимации — только через `.reveal`; без тяжёлых библиотек.
- Проверяй адаптив на 1100px и 720px.

## Контент
- Не выдумывай отзывы, кейсы, цифры результатов и цены.
- Тон: уверенный, конкретный, про пользу для бизнеса (клиенты, заявки, продажи).

## Возможные следующие задачи
1. Подключить форму через Netlify Forms (атрибуты `name`, `data-netlify="true"`, скрытое поле `form-name`).
2. Детальные страницы услуг (`services/yandex-business.html` и т.д.) на основе `.svc-card` + `.ticks` + `.process`.
3. Страницы «О компании» и «Контакты».
4. Вынести шапку/подвал в общий шаблон, если проект перейдёт на генератор (Astro/11ty).
